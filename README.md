# 小紅書童裝供應商爬蟲

小紅書童裝供應商爬蟲 - 帶暗語私訊功能版本

## 功能特點

- 🔍 **關鍵字搜索** - 搜索童裝代理、批發、一件代發等關鍵字
- 👤 **供應商提取** - 自動提取供應商信息（暱稱、簡介、粉絲數、筆記數等）
- 📱 **微信提取** - 自動從簡介中提取微信號
- 💬 **暗語私訊** - 使用暗語自動發送私訊（低頻率，避免被封）
- 📥 **回覆檢查** - 檢查供應商的私訊回覆
- 📊 **Excel 導出** - 導出供應商列表到 Excel 文件
- 💾 **數據持久化** - CSV 存儲，支持斷點續爬

## 安裝

```bash
# 1. 安裝 Python 依賴
pip install -r requirements.txt

# 2. 安裝 Playwright 瀏覽器
playwright install chromium
```

## 使用方法

```bash
python xhs_scraper.py
```

### 操作選項

| 選項 | 功能 |
|------|------|
| 0 | 🔐 手動登入小紅書（首次使用必選）|
| 1 | 🔍 搜索供應商 |
| 2 | 💬 發送私訊（暗語）|
| 3 | 📥 檢查回覆 |
| 4 | 📊 導出 Excel |
| 5 | 📋 查看統計 |
| 6 | 🚪 退出 |

## 配置說明

在 `xhs_scraper.py` 文件頂部可以修改以下配置：

```python
# 搜索關鍵字
KEYWORDS = [
    "童裝代理",
    "童裝批發招商",
    "婴儿连体衣批發",
    # ...
]

# 爬蟲配置
MAX_PAGES = 2           # 每個關鍵字最大頁數
MAX_SUPPLIERS = 50      # 最大供應商數量
HEADLESS = False        # 是否隱藏瀏覽器（調試時設為 False）

# 私訊配置
ENABLE_MESSAGE = True           # 是否啟用私訊功能
MAX_MESSAGES_PER_RUN = 5        # 每次最多發送幾條私訊
MESSAGE_DELAY_MIN = 300         # 發私訊最小間隔（秒）= 5分鐘
MESSAGE_DELAY_MAX = 600         # 發私訊最大間隔（秒）= 10分鐘
```

## 暗語訊息

程式內置多種暗語訊息模板，會隨機選擇發送：

- 加微信暗語：伽V、加嘉、加薇、夾V、加徽
- 看主頁暗語：煮頁、看主、煮叶
- 私信暗語：si我、絲我、斯聊
- 懂的來暗語：薰的來、懂的懂

## 輸出文件

- `suppliers_data.csv` - 供應商數據（自動保存）
- `output/童裝供應商_YYYYMMDD_HHMMSS.xlsx` - Excel 導出文件
- `browser_data/` - 瀏覽器登入狀態（自動保存）

## 注意事項

⚠️ **重要提醒**：

1. 首次使用請先選擇「0. 手動登入」，掃碼登入小紅書
2. 私訊功能有較長的時間間隔（5-10分鐘），避免被平台偵測
3. 請合理使用，避免頻繁爬取導致帳號被封
4. 本工具僅供學習研究使用
