## 魔法跳跳橋 Magic Bouncy Bridge

適合 5 歲小朋友的超可愛跳跳橋遊戲！

### macOS 安裝與執行

```bash
# 1. 安裝 pygame（macOS 用 pip3）
pip3 install pygame

# 2. 下載專案
git clone https://github.com/justin74185296/Telegram-bot.git
cd Telegram-bot
git checkout cursor/presence-check-logic-27e2

# 3. 執行遊戲
python3 magic_bridge_game.py
```

### Windows 安裝與執行

```bash
pip install pygame
python magic_bridge_game.py
```

### 操作方式

| 操作 | 說明 |
|------|------|
| 滑鼠點畫面上半部 / 按 ↑ 或 ← | 選上面的墊子 |
| 滑鼠點畫面下半部 / 按 ↓ 或 → | 選下面的墊子 |
| 空格鍵 | 開始遊戲 |
| R 鍵 | 重新開始 |
| ESC | 離開遊戲 |
