# 🎯 Polymarket Multi-Agent Trading System

## 多代理預測市場交易系統

一個基於 CrewAI + LangChain + Anthropic Claude API 構建的模擬交易代理團隊，專為 Polymarket（基於 Polygon 的預測市場）設計。

> ⚠️ **模擬模式**: 目前系統運行在模擬模式下，所有交易都是模擬的，不會執行真實下單。

## 👥 團隊成員

### 1. 👔 監督官 (Supervisor) - Claude Opus 4.5
- **角色**: 團隊經理、最終決策者、風險控制者
- **任務**:
  - 接收所有策略 agent 的信號
  - 主持和評估辯論過程
  - 做出最終交易建議
  - 嚴格執行風險控制規則
- **風險控制**:
  - 單筆交易 ≤ 總資金 5%
  - 總曝險 ≤ 20%
  - 分歧 > 30% 時增加辯論輪次
  - 分歧 > 40% 時請求人類介入

### 2. 📈 動量交易員 (Momentum Trader) - Claude Sonnet 4.5
- **角色**: 趨勢跟隨策略專家
- **任務**:
  - 偵測價格趨勢（上漲/下跌動能）
  - 分析成交量變化
  - 計算動量指標
- **輸出**: 買/賣信號 + 信心分數 (0-100) + 主要理由

### 3. 📊 均值回歸交易員 (Mean Reversion Trader) - Claude Sonnet 4.5
- **角色**: 統計套利策略專家
- **任務**:
  - 計算 Z-Score 和統計偏離
  - 偵測超買/超賣狀態
  - 預測價格回歸
- **輸出**: 反向信號 + 信心分數 + 統計依據

### 4. ⚖️ 套利交易員 (Arbitrage Trader) - Claude Sonnet 4.5
- **角色**: 無風險套利專家
- **任務**:
  - 檢查 YES + NO 價格偏離
  - 評估流動性和滑點
  - 計算套利收益
- **輸出**: 套利機會 + 預期收益 + 風險評估

### 5. 🔍 數據優化師 (Data Optimizer) - Claude Sonnet 4.5
- **角色**: 數據收集與策略優化專家
- **任務**:
  - 收集市場數據、新聞、輿情
  - 分析歷史表現
  - 提出策略優化建議
  - 維護團隊知識庫

## ✨ 核心功能

### 🗣️ 多輪辯論機制
- 2-4 輪辯論（根據分歧程度自動決定）
- 每個 agent 可以同意、反駁、補充證據
- 監督官主持，決定是否繼續

### 🤝 人類介入 (Human-in-the-Loop)
觸發條件：
- Agent 分歧 > 40%
- 涉及大額交易 (> 4% 投資組合)
- 重大策略變更

### 📊 風險管理
- 單筆交易限制: 5%
- 總曝險限制: 20%
- 自動止損設定
- 風險回報比計算

### 🎮 模擬模式
- 所有下單都是模擬的
- 輸出格式: `print("模擬下單：買 YES 100 股 @ 0.45")`
- 追蹤模擬績效

## 📦 安裝指南

### 1. 克隆專案
```bash
git clone <repository-url>
cd polymarket_agents
```

### 2. 創建虛擬環境
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows
```

### 3. 安裝依賴
```bash
pip install -r requirements.txt
```

### 4. 設置環境變數
```bash
export ANTHROPIC_API_KEY='your-api-key-here'
```

或創建 `.env` 文件：
```
ANTHROPIC_API_KEY=your-api-key-here
```

## 🚀 使用方法

### 互動模式
```bash
python -m polymarket_agents.main --interactive
```

### 分析特定市場
```bash
python -m polymarket_agents.main --market "will-bitcoin-reach-100k-2025" \
    --question "Will Bitcoin reach $100,000 by end of 2025?"
```

### 列出可用的模擬市場
```bash
python -m polymarket_agents.main --list-markets
```

### 運行範例
```bash
python -m polymarket_agents.example_run
```

### 程式化使用
```python
from polymarket_agents.crew import create_crew, analyze

# 方法 1: 使用 crew 物件
crew = create_crew()
results = crew.analyze_market(
    market_id="will-bitcoin-reach-100k-2025",
    market_question="Will Bitcoin reach $100,000 by end of 2025?"
)

# 方法 2: 快速分析
results = analyze("will-bitcoin-reach-100k-2025")
```

## ⚙️ 配置說明

### 模型配置 (config.py)
```python
MODEL_CONFIG = {
    "supervisor": {
        "model": "claude-sonnet-4-20250514",  # 最高階模型
        "temperature": 0.2,
        "max_tokens": 8192,
    },
    "momentum_trader": {
        "model": "claude-sonnet-4-20250514",
        "temperature": 0.3,
        "max_tokens": 4096,
    },
    # ... 其他 agent
}
```

### 風險配置
```python
@dataclass
class RiskConfig:
    max_single_trade_percent: float = 5.0      # 單筆限制
    max_total_exposure_percent: float = 20.0   # 總曝險限制
    disagreement_threshold: float = 30.0       # 辯論閾值
    max_debate_rounds: int = 4                 # 最大辯論輪數
    min_debate_rounds: int = 2                 # 最小辯論輪數
```

## 🔧 工具說明

### 市場數據工具
| 工具 | 功能 | 輸出 |
|------|------|------|
| `get_polymarket_data` | 獲取即時市場數據 | 價格、成交量、流動性 |
| `get_orderbook` | 獲取訂單簿 | 買賣盤深度 |
| `get_historical_prices` | 獲取歷史價格 | 時間序列數據 |
| `calculate_statistics` | 計算統計指標 | 均值、標準差、Z-Score |

### 輿情分析工具
| 工具 | 功能 | 輸出 |
|------|------|------|
| `search_x_sentiment` | X/Twitter 輿情 | 情緒分數、關鍵詞 |
| `web_search_news` | 新聞搜索 | 新聞列表、情緒 |
| `analyze_combined_sentiment` | 綜合輿情 | 整合分析 |

### 交易工具
| 工具 | 功能 | 輸出 |
|------|------|------|
| `simulate_order` | 模擬下單 | 訂單詳情 |
| `calculate_position_size` | 計算倉位 | 建議規模 |
| `check_risk_limits` | 風險檢查 | 合規結果 |
| `analyze_arbitrage_opportunity` | 套利分析 | 機會評估 |
